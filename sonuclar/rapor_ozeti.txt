Project Title               : CIFAR-10 Görüntü Sınıflandırma: ImageNet Ön-Eğitimli ResNet18 ile Transfer Öğrenme
Problem/Task                : Çok sınıflı görüntü sınıflandırma (10 sınıf)
Dataset                     : CIFAR-10 (60.000 adet 32x32 RGB; split: 45000 train / 5000 val / 10000 test, seed=42)
Dataset URL                 : https://www.cs.toronto.edu/~kriz/cifar.html
Model Architecture          : ResNet18 (torchvision, ImageNet1K_V1 ön-eğitimli), fc 512->10, tüm katmanlar fine-tune, 11.18M parametre
Input Size                  : 128x128x3 (32x32'den büyütülmüş, ImageNet normalizasyonu)
Hyperparameters             : lr=0.001, batch size=128, epochs=4, weight decay=0.05, cosine LR schedule, AMP (fp16), augment: RandomResizedCrop(0.7-1)+HFlip
Optimizer                   : AdamW (lr=0.001, weight_decay=0.05)
Activation/Output Function  : Gizli katmanlar ReLU; çıkış: logitler üzerinde Softmax
Loss Function               : CrossEntropyLoss
Evaluation Metrics          : Accuracy, Precision, Recall, F1 (macro + sınıf bazlı), Confusion Matrix, öğrenme eğrileri, eğitim/çıkarım süresi
Training Environment        : Google Colab, Tesla T4, PyTorch 2.14.1+cu130
Best Performance            : Test Acc=0.9414, Precision(macro)=0.9414, Recall(macro)=0.9414, F1(macro)=0.9413 | en iyi Val Acc=0.9450 (epoch 4)
Inference Time              : 3.13 ms/görüntü (batch=1), throughput 8928 görüntü/s (batch=256)
Deployment Technology       : Gradio (Colab'da share=True public link; app.py ile yerel)
Repository                  : https://github.com/hamxaaa00/cifar10-resnet18-goruntu-siniflandirma
